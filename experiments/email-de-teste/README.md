# E-mail de teste — Mail completo

Versão 0.1.2 do plugin privado **E-mail de teste** (`email-de-teste`). Ele usa o endpoint do Vértice Mail sem filtro de perfil e disponibiliza as mesmas seis ferramentas do plugin original:

- `list_messages`
- `get_message`
- `list_contacts`
- `send_email`
- `reply_email`
- `mark_as_read`

O servidor padrão mantém a caixa simulada do usuário. Enviar ou responder registra a mensagem em Enviados, sem entrega externa. O usuário deve revisar e confirmar o rascunho antes de cada envio ou resposta.

Conecte com a conta Laguna. Após atualizar a versão do plugin, atualize ou reconecte a conexão MCP se o ChatGPT ainda mostrar o catálogo anterior.
